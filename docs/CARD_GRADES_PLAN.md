# 카드 등급 개편 기획 (2026-09-05 초안)

사용자 지시를 정리한 것이다. 확정 전이며, 아래 "결정 필요" 항목의 답을 받은 뒤 코드로 옮긴다.

## 1. 지시 요약

- 정규 등급은 **일반 · 실버 · 골드 · (라이브 자리)** 네 단계.
- **「라이브」라는 이름은 정규 등급에서 뺀다.** 라이브는 원래 "특정 기간에만 나오는 카드"라는
  뜻이므로, 앞으로 기간제 카드 유형을 낼 때 그 이름을 쓴다(수준은 지금의 라이브와 동급).
- 지금 정규 등급 「라이브」(내부 `Live`)에는 **새 이름**이 필요하다.
- **월드 카드**(내부 `World`, 지금 표시명 「레전드」)는 **현재 소속팀 카드가 아니라, 과거 특정 팀에서
  리그 MVP급 활약을 한 시즌의 카드**다. 당시 팀 소속·당시 시즌 표기로 나오고, 라이브(새 이름)보다
  위다. 따라서 **현재 스쿼드 카드의 최상위는 라이브(새 이름)까지**이고, 월드는 과거 시즌 카드에만 쓴다.
- 월드 카드 후보(과거 레전드)는 Claude가 먼저 정리해 사용자 검토를 받는다 → 3절.

| World | 레전드 | **월드** | 과거 시즌 MVP급, 당시 팀·시즌 표기 | 90~97 |
| (신규 유형) | — | **라이브** | 기간제 카드. 등급이 아니라 유형(배지·기간). 수준은 플래티넘급 | 82~89 |

- 내부 타입 이름(`Normal/Rare/Legend/Live/World`)은 세이브 키에 박혀 있어 바꾸지 않는다. 표시명만 바꾼다
  (지금도 `Legend`=골드, `World`=레전드로 어긋나 있고 `RARITY_STYLES[x].label` 이 유일한 기준이다).
- 기간제 「라이브」는 등급이 아니라 **카드 유형 플래그**(`kind: 'live'`, 기간, 배지)로 둔다. 등급은
  플래티넘과 같은 `Live` 타입을 재사용하면 레벨 상한·훈련 비용 표가 그대로 맞는다.

1. 리그당 5명이 적당한가, 첫 출시 수량(예: 20장)과 추가 주기.
2. 같은 선수의 다른 시즌 카드(호날두 맨유/레알, 팔카오 포르투/아틀레티코, 즐라탄 인테르/PSG)를 허용할지.
3. 종합 90~97 배분과 최고점(메시 97)이 적절한지. 현 스쿼드 최상위(플래티넘)는 89로 잡을 예정.
4. K리그 후보의 시대·구단 표기(대우→부산, 일화→성남)가 괜찮은지.

## 4. 구현 계획

1. **표시명 변경**: `RARITY_STYLES` 라벨을 라이브→플래티넘, 레전드→월드로. 도움말·패치노트·상점 문구 일괄 수정.
2. **현 스쿼드 천장**: `scripts/build-squad-cards.mjs` 의 `rarityFor` 에서 `World` 를 빼고 82 이상은 모두 `Live`.
   단, 이미 발급된 스쿼드 카드의 id 는 **등급 목록 안 위치**라 이동하면 뒤 카드 id 가 밀린다.
   → 변경 전 `data/idSnapshot-<날짜>.json`(id→가명)을 저장하고, `lib/rosterMigration.ts` 에 **옛 id → 새 id 매핑**(가명 기준)을
   추가해 세이브를 읽을 때 적용한다. 이관 로직은 이미 있으므로 한 단계만 더 붙인다.
3. **월드 카드 데이터**: `data/world/<리그>.json`(시즌·가명 클럽·가명·실명·포지션·종합·국적·생년) → 빌드 스크립트가
   `SQUAD_ROSTER.World` 뒤에 붙임. `PlayerDef.season`(예: "2003-04") 필드를 추가하고 카드에 작은 시즌 표기.
   실명 힌트는 기존 `SQUAD_REAL_HINTS` 경로.
4. **기간제 라이브 유형**(추후): `PlayerDef.kind: 'live'`, `availableFrom/Until`, 카드 배지. 등급 타입은 `Live` 재사용.
   뽑기 풀은 기간 안에서만 포함. 별도 문서로.
5. **확률**: 월드는 프리미엄에만, 현재 3%(레전드 자리)를 그대로 쓰되 노브로 조절. 일반 스카우트에서는 0으로.
6. **순서**: ①검토 회신 → ②표시명·천장·id 스냅샷·이관(하루) → ③월드 카드 1차 20~40장 데이터 + 시즌 표기(하루) →
   ④선수편집으로 능력치 보정 → ⑤공지.
