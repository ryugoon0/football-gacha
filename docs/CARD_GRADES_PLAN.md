# 카드 등급 개편 기획 (2026-09-05)

사용자 지시를 정리한 것이다. 5절의 결정은 회신을 받아 확정했고, 4절 ①·②는 코드에 반영됐다.

## 0. 확정된 결정 (2026-09-05 회신)

- 정규 사다리 **일반 < 실버 < 골드 < 플래티넘**, 최상위 **월드**. 표시명 반영 완료.
- 「라이브」는 등급이 아니라 **기간제 컨셉 카드**(그 주·그 달의 활약 선수 등)의 유형 이름. 별도 문서에서 설계.
- **월드**는 과거 레전드를 당시 시즌 능력치·당시 소속팀으로 낸다. **순차 출시**: 팀의 성적과 위상에 따라 팀별
  출시 장수가 다르고, 지금 전부 준비하지 않는다. 후보군만 넉넉히 정리해 두고(3절) 배치별로 고른다.
- **같은 선수 중복 허용**: 정규 카드도 시즌제로 갈 것이라 시즌별 정규 카드·라이브 카드·월드 카드가 같은
  선수일 수 있다(호날두 07-08 맨유 / 13-14 레알 둘 다 가능).
- **능력치는 등급 사이에 겹칠 수 있다.** 등급을 가르는 것은 **히든 능력치**다. 현재 히든 범위(0~12):
  일반 0~3 · 실버 2~5 · 골드 5~8 · 플래티넘 7~10 · 월드 9~12 — 월드는 히든이 반드시 플래티넘 위에 있어야
  하며, 월드 데이터에는 `hidden` 을 명시해 겹치지 않게 한다.
- 현 스쿼드 카드는 종합이 아무리 높아도 **플래티넘까지**. id 가 등급 목록 위치라 목록은 그대로 두고
  `RosterExtras.rarity='Live'` 로 등급만 내렸다(월드 목록에 있던 현역 카드 전부, 수기·생성 명단 포함).

## 1. 지시 요약

- 정규 등급은 **일반 · 실버 · 골드 · (라이브 자리)** 네 단계.
- **「라이브」라는 이름은 정규 등급에서 뺀다.** 라이브는 원래 "특정 기간에만 나오는 카드"라는
  뜻이므로, 앞으로 기간제 카드 유형을 낼 때 그 이름을 쓴다(수준은 지금의 라이브와 동급).
- 지금 정규 등급 「라이브」(내부 `Live`)에는 **새 이름**이 필요하다.
- **월드 카드**(내부 `World`, 지금 표시명 「레전드」)는 **현재 소속팀 카드가 아니라, 과거 특정 팀에서
  리그 MVP급 활약을 한 시즌의 카드**다. 당시 팀 소속·당시 시즌 표기로 나오고, 라이브(새 이름)보다
  위다. 따라서 **현재 스쿼드 카드의 최상위는 라이브(새 이름)까지**이고, 월드는 과거 시즌 카드에만 쓴다.
- 월드 카드 후보(과거 레전드)는 Claude가 먼저 정리해 사용자 검토를 받는다 → 3절.

- 내부 타입 이름(`Normal/Rare/Legend/Live/World`)은 세이브 키에 박혀 있어 바꾸지 않는다. 표시명만 바꾼다
  (지금도 `Legend`=골드, `World`=레전드로 어긋나 있고 `RARITY_STYLES[x].label` 이 유일한 기준이다).
- 기간제 「라이브」는 등급이 아니라 **카드 유형 플래그**(`kind: 'live'`, 기간, 배지)로 둔다. 등급은
  플래티넘과 같은 `Live` 타입을 재사용하면 레벨 상한·훈련 비용 표가 그대로 맞는다.

## 4. 구현 계획

1. ~~**표시명 변경**~~ — 반영(2026-09-05). `RARITY_STYLES` 라이브→플래티넘, 레전드→월드. 도움말·노브 문구 수정.
2. ~~**현 스쿼드 천장**~~ — 반영. id 이동 없이 `RosterExtras.rarity='Live'` 로 등급만 내렸다(월드 목록의 현역 카드 전부).
   `PLAYERS_BY_RARITY.World` 는 레전드가 나오기 전까지 비어 있고, 뽑기·조각 교환·합성은 비어 있는 등급을 만나면 한
   등급 아래로 내려간다(`releasedPoolFor`). 월드 확률 노브는 그대로 두되 출시 전에는 실질적으로 플래티넘으로 떨어진다.
3. **월드 카드 데이터** — 빌드 스크립트의 `data/world/*.json` 지원과 `PlayerDef.season`(상세 모달 표기)은 반영. 남은 것은
   데이터 작성(3-3절 1차 배치)과 카드 얼굴의 시즌 표기, 월드 전용 카드 프레임.
4. **기간제 라이브 유형**(추후): `PlayerDef.kind: 'live'`, `availableFrom/Until`, 카드 배지. 등급 타입은 `Live` 재사용.
   뽑기 풀은 기간 안에서만 포함. 별도 문서로.
5. **확률**: 월드는 프리미엄에만, 현재 3%(레전드 자리)를 그대로 쓰되 노브로 조절. 일반 스카우트에서는 0으로.
6. **순서**: ①검토 회신 → ②표시명·천장·id 스냅샷·이관(하루) → ③월드 카드 1차 20~40장 데이터 + 시즌 표기(하루) →
   ④선수편집으로 능력치 보정 → ⑤공지.
