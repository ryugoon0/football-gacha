# 게임 화면 AI 비서 캐릭터 후보 (검토용, 미구현)

2026-09-04. 게임 화면에 붙일 AI 비서 캐릭터 후보 3명(여성). 이름·설정은
전부 가상이며 실존 인물을 빗대지 않았다(로스터의 실명 금지 원칙과 같다).
셋 중 하나를 고르거나 요소를 섞어 확정한 뒤 화면 배치·대사 체계를 설계한다.

역할(공통): 로그인 인사, 오늘 할 일 안내(데일리 미션·미니게임·PvP 잔여 횟수),
경기 결과 브리핑, 경쟁 리그 킥오프·정산 알림, 스쿼드 문제(빈 자리·부상) 경고,
초보 가이드(GuideOverlay 대체). 능력치를 올려 주는 존재가 아니라 "말해 주는"
존재 — 게임 판정에는 관여하지 않는다.

---

## 후보 1 — 서지안 (徐智安) · 수석 데이터 분석관

- **한 줄**: 숫자로 말하는 냉정한 분석가. 감정 표현은 적지만 정확하다.
- **설정**: 20대 후반. 구단 분석실 출신. 경기 이벤트·점유율·슛 수치를 근거로
  조언한다. 칭찬에 인색하지만 결과가 좋으면 "예상 범위 안입니다" 정도로
  인정한다.
- **말투**: 존댓말, 짧은 문장, 수치 인용. 감탄사 없음.
  - "오늘 경기 점유율 58%, 유효 슈팅 6. 결과 3:1은 우연이 아닙니다."
  - "왼쪽 풀백 컨디션 41. 이대로 내보내면 후반에 무너집니다."
  - "데일리 PvP 2회 남았습니다. 상대는 검색해 두었습니다."
- **비주얼 방향**: 단정한 흑발 로우 포니테일, 얇은 안경, 네이비 셔츠에
  태블릿. 배경은 분석실 모니터 불빛. 표정 변화 3단계(무표정/미세한 미소/
  살짝 찌푸림)면 충분.
- **어울리는 UI 자리**: 경기 결과 화면·전술 리포트 옆. 데이터 톤이라
  히든 능력치/운영자 화면과도 위화감 없음.
- **리스크**: 초보 유저에게 차갑게 느껴질 수 있음. 초반 가이드 톤은 별도
  대사 세트 필요.

## 후보 2 — 한아름 · 신입 코치 겸 매니저

- **한 줄**: 밝고 열정적인 신입. 감독(플레이어)을 진심으로 응원한다.
- **설정**: 20대 초중반. 대학 축구부 매니저 출신으로 이번 시즌 구단에
  합류. 실수도 하지만 매일 성장하는 캐릭터 — 플레이어의 진행도(디비전
  승격, 첫 레전드 카드 등)에 맞춰 대사가 함께 자란다.
- **말투**: 존댓말이지만 활기참, 감탄사·이모지 느낌의 어미. 결과가 나쁘면
  같이 속상해하고 다음 경기를 북돋운다.
  - "감독님! 오늘 3:1 승리예요, 스트라이커가 두 골이나 넣었어요!"
  - "앗, 벤치에 골키퍼가 없어요… 자동 배치 한 번 눌러 볼까요?"
  - "경쟁 리그 다음 경기 10시 킥오프! 이번엔 꼭 봐요, 저도 볼게요."
- **비주얼 방향**: 밝은 갈색 단발, 구단 트레이닝 재킷, 목에 호루라기 또는
  클립보드. 표정 변화 폭 큼(기쁨/놀람/시무룩/결의) — 표정 수가 많을수록
  살아난다.
- **어울리는 UI 자리**: 홈 탭 인사·데일리 미션·초보 가이드. 캐주얼 모드
  톤과 가장 잘 맞음.
- **리스크**: 과하면 시끄럽다. 알림 빈도 상한과 "조용히" 토글 필요.

## 후보 3 — 백소연 · 구단 사무국장

- **한 줄**: 20년 차 베테랑. 여유 있고 위트 있는 멘토.
- **설정**: 40대. 선수 출신은 아니지만 구단의 흥망을 여러 번 봤다. 잔소리
  대신 한마디로 정곡을 찌르고, 플레이어가 흔들릴 때 가장 든든하다. 경쟁
  리그·이적시장·재정(골드) 같은 "운영" 영역에서 특히 존재감.
- **말투**: 부드러운 존댓말, 가끔 반농담. 서두르지 않는다.
  - "3:1이면 됐어요. 오늘은 골 넣은 애들 칭찬이나 해 주세요."
  - "골드가 좀 헐렁하네요. 이적시장은 내일 봐도 안 늦어요."
  - "경쟁 리그 첫 경기는 원래 다 떨려요. 라인업만 제대로 냈으면 반은 한 겁니다."
- **비주얼 방향**: 은빛 도는 짧은 머리 또는 올림머리, 재킷에 구단 배지,
  손에 머그컵. 사무실 창가. 표정은 잔잔한 미소 중심, 놀람·정색 각 1개.
- **어울리는 UI 자리**: 경쟁 리그 탭·이적시장·상점·시즌 마무리 화면.
- **리스크**: 젊은 타깃층에게 거리감. 다만 "든든한 어른" 포지션은 비서
  캐릭터로 흔치 않아 차별점이 된다.

## 추천

단독이면 **후보 2 한아름** — 이 게임의 첫 접점(홈·가이드·데일리)이 가장
넓고, 캐주얼 모드·데일리 PvP의 가벼운 톤과 맞는다. 다만 "성장하는
캐릭터"라는 설정이 대사 체계 설계를 요구하므로, 1차는 고정 대사 30개
내외로 시작하고 진행도 연동은 나중에 붙인다.

두 명을 쓸 여유가 있다면 **한아름(홈·캐주얼) + 서지안(경기 결과·경쟁
리그)** 조합이 화면별 톤 분리가 자연스럽다.

## 확정 뒤 할 일

1. 캐릭터 1명 확정 → 이름·표정 세트(3~5개)·대사 카테고리 정의
2. 대사 데이터 파일(`lib/assistant.ts`)과 트리거(로그인, 경기 종료, 킥오프
   1시간 전, 스쿼드 문제 감지) 설계
3. 화면 자리: 홈 탭 상단 카드 + 알림 토스트, "조용히" 토글
4. 일러스트 발주 사양(비주얼 방향 절 기반)
