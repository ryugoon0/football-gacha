# Football Day — 축구 카드 매니저

풋볼데이 스타일의 축구 카드 수집·매니지먼트 게임입니다. 카드팩과 이적시장으로 선수를 모으고,
스쿼드를 짜고, 8팀 리그와 FA컵을 치르며 승격과 우승을 노립니다. Next.js App Router + TypeScript +
Tailwind CSS로 만들었고, 서버나 데이터베이스 없이 브라우저에서 완결됩니다.

## 게임 흐름

1. **뽑기** — 하루 한 번 무료 뽑기, 1회(300G) / 10연차(2700G). 10연차는 레어 이상 1장 보장.
   확률은 노멀 70% · 레어 20% · 레전드 5% · 라이브 3% · 월드 2%.
   일일 미션 3종(뽑기·승리·강화)을 채우면 골드를 받습니다.
2. **이적시장** — 매일 5명의 매물이 올라오고, 골드로 원하는 선수를 지목해 영입합니다.
   300G를 내면 매물을 즉시 새로 뽑습니다. 상위 리그일수록 좋은 매물이 나옵니다.
3. **스쿼드** — 4-3-3 / 4-4-2 / 4-2-3-1 / 3-5-2 전술판에서 자리를 눌러 선수를 배치하거나
   자동 배치. 전술은 공격적 / 균형 / 수비적 중 선택. 포지션이 맞을수록 케미와 팀 전력이 오릅니다.
4. **선수단** — 등급·포지션 필터, 강화(레벨당 전 능력치 +1, 최대 10), 방출, 중복 일괄 방출, 도감.
   **승급 합성**: 같은 등급 카드 3장 + 500G → 한 단계 위 등급 카드 1장.
   **체력·부상**: 경기에 나간 선수는 체력이 떨어지고(전력 최대 -15%) 가끔 부상으로 결장합니다.
   벤치에서 쉬면 회복되고, 골드로 즉시 회복·치료할 수도 있습니다. 새 시즌에는 전원 회복됩니다.
5. **경기** — 리그와 FA컵 두 대회를 뜁니다.
   - **리그**: 8팀 · 7라운드. 내 경기는 90분 텍스트 중계로 진행되고 같은 라운드의 다른 경기도
     함께 시뮬레이션되어 순위표가 갱신됩니다. 2위 안은 승격, 7위 아래는 강등, 순위별 시즌 보상.
   - **FA컵**: 8팀 녹아웃(8강 → 4강 → 결승). 비기면 승부차기, 지면 그 시즌 컵은 종료.
     라운드를 올라갈수록 상금이 커지고 우승하면 트로피가 쌓입니다.

- 선수 61명, 5등급, 12개 포지션. 능력치는 포지션별 가중치로 계산한 오버롤(OVR)로 표시됩니다.
- 카드 일러스트는 선수 ID에서 결정되는 SVG로 그려집니다(이미지 파일 없음).
- 진행 상황은 `localStorage`에 자동 저장되고, 세이브 버전이 올라가도 기존 진행은 이어집니다.
  하단의 **게임 초기화**로 처음부터 다시 시작할 수 있습니다.
- 처음 접속하면 4단계 안내가 뜨고, 헤더의 **도움말** 버튼으로 언제든 다시 볼 수 있습니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # 게임 규칙 단위 테스트 (88개)
npm run typecheck  # 타입 검사
npm run lint
npm run build && npm start
```

푸시하면 GitHub Actions(`.github/workflows/ci.yml`)가 타입 검사 → 린트 → 테스트 → 빌드를 자동으로 돌립니다.

## 구조

```
app/
  layout.tsx            루트 레이아웃 / 메타데이터
  page.tsx              엔트리
  api/gacha/route.ts    카드 뽑기 API (?count=1..10)
components/
  GachaGame.tsx         헤더 + 탭 셸
  GameProvider.tsx      게임 상태 컨텍스트 · localStorage 저장
  GuideOverlay.tsx      첫 방문 안내 / 도움말
  MatchBroadcast.tsx    경기 중계 UI (리그 · 컵 공용)
  useLiveMatch.ts       90분 중계 재생 훅
  PlayerCard.tsx        카드 UI
  PlayerAvatar.tsx      선수 ID 기반 SVG 초상
  tabs/                 뽑기 · 이적시장 · 스쿼드 · 선수단 · 경기 화면
lib/
  players.ts            선수 로스터와 능력치 생성
  gacha.ts              확률과 뽑기 로직 (API와 클라이언트 공용)
  formations.ts         포메이션과 전술판 좌표
  tactics.ts            전술별 보정치
  squad.ts              포지션 적합도 · 케미 · 팀 전력 계산
  match.ts              내 경기 시뮬레이션과 보상
  league.ts             시즌 일정 · 순위표 · 승격/강등
  cup.ts                FA컵 대진 · 승부차기 · 상금
  condition.ts          체력 소모 · 부상 · 회복 비용
  market.ts             이적 매물과 가격
  fusion.ts             승급 합성 규칙
  daily.ts              일일 미션과 무료 뽑기
  gameReducer.ts        모든 게임 규칙이 모인 리듀서 (테스트 대상)
  storage.ts            세이브 데이터와 버전 마이그레이션
tests/                  vitest 단위 테스트
```

등장하는 선수·클럽 이름은 모두 가상의 이름입니다.
