# Football Day — 축구 카드 매니저

풋볼데이 스타일의 축구 카드 수집·매니지먼트 게임입니다. 카드팩과 이적시장으로 선수를 모으고,
스쿼드를 짜고, 8팀 리그와 FA컵을 치르며 승격과 우승을 노립니다. Next.js App Router + TypeScript +
Tailwind CSS로 만들었고, 서버나 데이터베이스 없이 브라우저에서 완결됩니다.

## 게임 흐름

1. **뽑기** — 하루 한 번 무료, 기본 팩(300G) / 포지션 지정 팩(600G) / 실버 확정 팩(1000G) /
   10연차(2700G, 실버 이상 보장). 카드 등급은 **일반 · 실버 · 골드 · 라이브 · 월드**이고
   확률은 70% · 20% · 5% · 3% · 2%, 실제 내 배출 기록도 함께 보여줍니다.
   - **천장**: 30회 안에 레전드 이상이 반드시 나옵니다(뽑으면 초기화)
   - **주간 픽업**: 매주 바뀌는 픽업 선수는 같은 등급이 나올 때 절반 확률로 등장
   - **조각 교환소**: 선수를 방출하면 골드와 조각을 받고, 조각으로 등급 확정 카드를 교환
   - 일일 미션 3종(뽑기·승리·강화)을 채우면 골드를 받습니다
2. **이적시장** — 매일 5명의 매물이 올라오고, 원하는 선수를 지목해 영입합니다.
   **일반 · 실버 등급만 이적 대상**이며 골드 이상은 카드팩과 합성으로만 얻습니다.
   300G를 내면 매물을 즉시 새로 뽑습니다.
3. **스쿼드** — 4-3-3 / 4-4-2 / 4-2-3-1 / 3-5-2 전술판 + **벤치 7명**. 전술은 공격적 / 균형 /
   수비적, **자동 교체**를 켜면 부상·체력 저하(45 미만) 선발을 킥오프 전에 벤치와 바꿉니다.
   - **가능 포지션**: 선수마다 주 포지션과 보조 포지션이 정해져 있고, 그 밖의 자리에 넣으면
     능력치가 약 45% 깎입니다.
   - **팀 컬러**: 같은 클럽 3/5/7명, 같은 리그·국가 5/8/11명이면 단계별로 전력과 케미가 오릅니다
     (합산 상한 +14 전력 / +20 케미). 케미는 팀 전력을 최대 ±14% 흔듭니다.
   - **라인업 등록 제한**: 선발 11명의 레벨 합이 리그 상한을 넘으면 경기에 등록할 수 없습니다
     (5부 55 · 4부 66 · 3부 77 · 2부 89 · 1부 110).
4. **선수단** — 선수 관리 · 훈련 · 한계 돌파 · 승급 합성 · 일괄 방출 다섯 가지 모드.
   - **상세 보기**: 카드를 고르고 *상세 보기*를 누르면 레벨 · 경험치(다음 레벨까지 남은 수치) ·
     능력치별 성장 여지(현재 / 한계 레벨 / 등급 상한) · 포지션별 능력치 · 세부 능력치 18개 ·
     특성 · 체력을 한 화면에서 볼 수 있습니다.
   - **일괄 방출**: 여러 명을 골라 한 번에 정리합니다. *중복 카드 · 일반 등급 전부 ·
     선발/벤치 제외 전부* 빠른 선택과 받게 될 골드 · 조각 미리보기를 제공합니다.
   - **레벨과 성장**: 카드는 등급별 시작 레벨로 나옵니다(일반 2 · 실버 3 · 골드/라이브 4~5 · 월드 5).
     **훈련**은 다른 카드를 재료로 먹여 경험치를 쌓아 레벨을 올리고, **한계 돌파**는 *같은 선수 카드*
     1장을 소모해 레벨 한계를 1 올립니다. 등급 상한은 일반 8 · 실버 9 · 골드/라이브/월드 10입니다.
   - **10레벨**이 되면 포지션 주요 능력치가 99까지 오릅니다. 골드와 라이브가 똑같이 99여도
     **히든 능력치**(결정력·체력·빅매치·기복, 화면에 보이지 않음)가 달라 실제 성능이 갈립니다.
   - **세부 능력치**: 6개 대분류 아래 18개 하위 능력치와 **포지션별 능력치**를 볼 수 있습니다.
   - **특성** 10종(스피드스타·침착한 마무리·수비의 벽·유리몸 …)이 득점·실점 확률, 공격 빈도,
     케미, 체력 소모와 부상 확률에 반영됩니다.
   - **경기 평점**: 출전하면 평점(4.0~10.0)만큼 경험치가 쌓여 저절로도 성장합니다.
   **승급 합성**: 같은 등급 카드 3장 + 500G → 한 단계 위 등급 카드 1장.
   **체력·부상**: 경기에 나간 선수는 체력이 떨어지고(전력 최대 -15%) 가끔 부상으로 결장합니다.
   벤치에서 쉬면 회복되고, 골드로 즉시 회복·치료할 수도 있습니다. 새 시즌에는 전원 회복됩니다.
5. **경기** — 리그와 FA컵이 **하나의 일정에 섞여** 진행됩니다(총 23경기일).
   - **리그**: 20개 팀 · 19라운드. 내 경기는 90분 텍스트 중계로 진행되고 같은 라운드의 다른
     경기도 함께 시뮬레이션되어 순위표가 갱신됩니다. 2위 안은 승격, 18위 아래는 강등.
   - **FA컵**: 16팀 녹아웃(16강 → 8강 → 4강 → 결승). 리그 라운드 사이에 끼어들며, 비기면
     승부차기, 지면 그 시즌 컵은 종료됩니다.
   - 연전이 이어지므로 체력 관리와 벤치 운용이 중요합니다.

- 선수 61명, 5등급, 12개 포지션. 능력치는 포지션별 가중치로 계산한 오버롤(OVR)로 표시됩니다.
- 카드 일러스트는 선수 ID에서 결정되는 SVG로 그려집니다(이미지 파일 없음).
- 진행 상황은 `localStorage`에 자동 저장됩니다. 카드·시즌 구조가 바뀌면서 세이브 키가
  `football-day-save-v2`로 바뀌었으므로, 이전 버전의 진행 상황은 이어지지 않고 새로 시작합니다.
  하단의 **게임 초기화**로 언제든 처음부터 다시 시작할 수 있습니다.
- 처음 접속하면 4단계 안내가 뜨고, 헤더의 **도움말** 버튼으로 언제든 다시 볼 수 있습니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # 게임 규칙 단위 테스트 (148개)
npm run typecheck  # 타입 검사
npm run lint
npm run build && npm start
```

푸시하면 GitHub Actions(`.github/workflows/ci.yml`)가 타입 검사 → 린트 → 테스트 → 빌드를 자동으로 돌립니다.

## 배포 (Vercel)

서버나 데이터베이스가 필요 없어서 별도 설정 없이 배포됩니다.

1. [vercel.com](https://vercel.com)에 GitHub 계정으로 로그인
2. **Add New → Project**에서 이 저장소를 **Import** (프레임워크는 Next.js로 자동 인식)
3. 환경 변수 없이 **Deploy**
4. 개발 브랜치를 그대로 보고 싶다면 Settings → Git → **Production Branch**를 해당 브랜치로 변경

친구들에게 공유해 테스트를 받는 방법은 [TESTING.md](./TESTING.md)에 정리해 두었습니다.

이후 푸시할 때마다 자동으로 다시 배포됩니다. 빌드 명령은 기본값(`npm run build`)을 쓰고,
설치는 `npm ci`로 이루어지므로 `package-lock.json`이 저장소에 있어야 합니다.
