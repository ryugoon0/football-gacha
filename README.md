# Football Day — 축구 카드 매니저

풋볼데이 스타일의 축구 카드 수집·매니지먼트 게임입니다. 카드팩과 이적시장으로 선수를 모으고,
스쿼드를 짜고, 8팀 리그와 FA컵을 치르며 승격과 우승을 노립니다. Next.js App Router + TypeScript +
Tailwind CSS로 만들었고, 서버나 데이터베이스 없이 브라우저에서 완결됩니다.

## 게임 흐름

0. **홈(감독실)** — 접속하면 라커룸 그림과 함께 오늘의 요약이 먼저 보입니다.
   다음 상대와 경기장 바로가기, 골드 · 보관함 · 스쿼드 전력 · 남은 미니게임,
   *오늘 할 일*(받을 미션 보상, 무료 뽑기, 빈 자리, 부상, 보관함 가득 참), 최근 5경기.
1. **뽑기** — 카드팩은 **일반팩**과 **프리미엄팩** 두 종류입니다.
   - 일반팩 1회 300G / 10연차 2700G(실버 이상 1장 보장)
   - 프리미엄팩 1회 1200G / 10연차 10800G(골드 이상 1장 보장)
   - 팩마다 확률표가 다르고 화면에 그대로 표시됩니다. **현재 확률은 테스트용**이라
     고급 카드가 잘 나오도록 맞춰져 있습니다(일반팩 골드 10% / 프리미엄팩 골드 33%).
   - **포지션 지정** 스위치로 원하는 자리의 선수만 뽑을 수 있고, 하루 한 번 무료 뽑기가
     있습니다. 지금까지 등급별로 몇 장 나왔는지 기록도 보여줍니다.
   - **천장**: 30회 안에 레전드 이상이 반드시 나옵니다(뽑으면 초기화)
   - **주간 픽업**: 매주 바뀌는 픽업 선수는 같은 등급이 나올 때 절반 확률로 등장
   - **조각 교환소**: 선수를 방출하면 골드와 조각을 받고, 조각으로 등급 확정 카드를 교환
   - 일일 미션 3종(뽑기·승리·강화)을 채우면 골드를 받습니다
2. **이적시장** — 매일 5명의 매물이 올라오고, 원하는 선수를 지목해 영입합니다.
   **일반 · 실버 등급만 이적 대상**이며 골드 이상은 카드팩과 합성으로만 얻습니다.
   300G를 내면 매물을 즉시 새로 뽑습니다.
3. **스쿼드** — 4-3-3 / 4-4-2 / 4-2-3-1 / 3-5-2 전술판 + **벤치 7명**.
   **자동 교체**를 켜면 부상·체력 저하(45 미만) 선발을 킥오프 전에 벤치와 바꿉니다.
   - **전술 프리셋**: 총공세 · 균형 · 역습 · 잠그기 네 가지를 한 번의 탭으로 바꿉니다.
   - **세부 조정**: 프리셋 아래를 펼치면 플랜(공격적/균형/수비적) · 압박(높음/보통/낮음) ·
     수비 라인(높게/보통/낮게) · 템포(빠르게/보통/느리게)를 따로 정할 수 있고, 네 다이얼이
     공격·수비 보정, 기회 빈도, 파울 빈도, 체력 소모, 역습 위험에 각각 반영됩니다.
   - PC에서는 단축키도 씁니다(플랜 `1 2 3` · 압박 `Q W E` · 라인 `A S D` · 템포 `Z X C`,
     `Space` 일시정지). 모바일이 기준이라 단축키는 어디까지나 보조 수단입니다.
   - **가능 포지션**: 선수마다 주 포지션과 보조 포지션이 정해져 있고, 그 밖의 자리에 넣으면
     능력치가 약 45% 깎입니다. **금지가 아니라 손해**라서, 자리에 맞는 선수가 없으면 다른
     포지션 선수라도 넣을 수 있습니다. 자동 배치와 자동 교체도 같은 규칙을 따르므로
     그 자리 선수가 부상당해도 빈 자리로 남지 않습니다(제 자리 선수를 먼저 채운 뒤,
     남은 자리에만 다른 포지션 선수를 씁니다).
   - **팀 컬러**: 같은 클럽 3/5/7명, 같은 리그·국가 5/8/11명이면 단계별로 전력과 케미가 오릅니다
     (합산 상한 +14 전력 / +20 케미). 케미는 팀 전력을 최대 ±14% 흔듭니다.
   - **라인업 등록 제한**: 선발 11명의 레벨 합이 리그 상한을 넘으면 경기에 등록할 수 없습니다
     (5부 55 · 4부 66 · 3부 77 · 2부 89 · 1부 110).
4. **선수단** — 선수 관리 · 훈련 · 한계 돌파 · 승급 합성 · 일괄 방출 다섯 가지 모드.
   모드를 고르면 그 모드가 무엇을 하는지와 걸리기 쉬운 규칙이 화면에 설명으로 뜹니다.
   **키우는 대상은 선발 선수여도 되고**(재료로 넣는 카드만 선발·벤치에서 빼면 됩니다),
   목록에서 다른 카드를 누르면 그 선수가 곧바로 새 대상이 됩니다.
   - **보관함**: 카드 한 장이 한 칸입니다. 시작 60칸이고 **+10칸씩 골드로 증설**해
     최대 200칸까지 늘립니다(증설할수록 비용 상승: 300G부터 시작). 보관함이 가득 차면
     뽑기 · 영입 · 조각 교환이 막히고, 화면에 몇 칸 남았는지 표시됩니다.
   - **상세 보기**: 카드를 고르고 *상세 보기*를 누르면 레벨 · 경험치(다음 레벨까지 남은 수치) ·
     능력치별 성장 여지(현재 / 한계 레벨 / 등급 상한) · 포지션별 능력치 · 세부 능력치 18개 ·
     특성 · 체력을 한 화면에서 볼 수 있습니다.
   - **일괄 방출**: 여러 명을 골라 한 번에 정리합니다. *일반 등급 전부 · 선발/벤치 제외 전부*
     빠른 선택과 받게 될 골드 · 조각 미리보기를 제공합니다.
     같은 선수를 이미 가진 카드에는 **돌파 재료** 표시가 붙고, 그런 카드를 골랐을 때는
     경고가 뜹니다. 중복 카드를 한 번에 파는 기능은 두지 않았습니다 —
     같은 선수 카드가 곧 한계 돌파 재료이기 때문입니다.
   - **레벨과 성장**: 카드는 등급별 시작 레벨로 나옵니다(일반 2 · 실버 3 · 골드/라이브 4~5 · 월드 5).
     **훈련**은 다른 카드를 재료로 먹여 경험치를 쌓아 레벨을 올리고, **한계 돌파**는 *같은 선수 카드*
     1장을 소모해 레벨 한계를 1 올립니다. 등급 상한은 일반 8 · 실버 9 · 골드/라이브/월드 10입니다.
   - **10레벨**이 되면 포지션 주요 능력치가 99까지 오릅니다. 골드와 라이브가 똑같이 99여도
     **히든 능력치**(결정력·체력·빅매치·기복, 화면에 보이지 않음)가 달라 실제 성능이 갈립니다.
   - **세부 능력치**: 6개 대분류 아래 18개 하위 능력치와 **포지션별 능력치**를 볼 수 있습니다.
   - **특성** 10종(스피드스타·침착한 마무리·수비의 벽·유리몸 …)이 득점·실점 확률, 공격 빈도,
     케미, 체력 소모와 부상 확률에 반영됩니다.
   - **경기 평점**: 출전하면 평점(4.0~10.0)만큼 경험치가 쌓여 저절로도 성장합니다.
   **승급 합성**: 같은 등급 카드 3장 + 500G → 한 단계 위 등급 카드 1장.
   **체력·부상**: 경기에 나간 선수는 체력이 떨어지고(전력 최대 -15%) 가끔 부상으로 결장합니다.
   벤치에서 쉬면 회복되고, 골드로 즉시 회복·치료할 수도 있습니다. 새 시즌에는 전원 회복됩니다.
5. **경기** — 리그와 FA컵이 **하나의 일정에 섞여** 진행됩니다(총 23경기일).
   - **관전 모드 / 텍스트 모드**: 관전 모드는 경기장 위에 22명을 바둑판알처럼 그려
     공을 따라 움직이는 모습을 보여주고, 텍스트 모드는 중계 문구만 봅니다. 언제든 전환됩니다.
   - **모바일 조작**: 경기 중에는 화면 아래에 고정 바가 떠서 전술 프리셋 4개 · 지친 선수 교체 ·
     직접 교체 · 일시정지를 엄지로 누를 수 있고, 대기 중인 지시 개수가 배지로 보입니다
     (44px 이상 탭 영역).
   - **경기 중 체력**: 선발은 1분마다 체력이 떨어지고, 압박이 강하고 템포가 빠를수록 더 빨리
     빠집니다(골키퍼는 거의 줄지 않습니다). 팀 평균 체력이 낮아지면 전력이 최대 15%까지
     깎이므로 후반에는 교체가 필요합니다. 화면에 **평균 체력**이 표시되고, 55 아래로 내려간
     선수는 교체 목록에서 노란색으로 보입니다.
   - **지친 선수 교체**: 버튼 하나로 체력이 55 아래인 선발을 벤치 최적 선수와 한 번에
     바꿉니다(가능 포지션과 리그 레벨 상한을 지킵니다). 경기 중 체력은 이 경기에만 적용되고,
     저장되는 선수 체력은 지금처럼 경기가 끝난 뒤에 반영됩니다.
   - **경기 중 개입**: 교체와 전술 지시는 **언제든 내릴 수 있고**, 실제 반영은 파울 · 골 ·
     아웃 · 하프타임처럼 **경기가 멈춘 순간**에 이루어집니다. 대기 중인 지시는 화면에
     목록으로 보이고 언제든 취소할 수 있습니다. 이미 멈춰 있을 때 내린 지시는 즉시
     적용됩니다. *중단 시 자동 정지*를 켜면 중단마다 시계가 멈추고, `Space`로 직접
     멈추고 재개합니다. 배속은 보통 · 빠르게 · 아주 빠르게 세 단계입니다.
   - **리그**: 20개 팀 · 19라운드. 내 경기는 90분 중계로 진행되고 같은 라운드의 다른
     경기도 함께 시뮬레이션되어 순위표가 갱신됩니다. 2위 안은 승격, 18위 아래는 강등.
   - **FA컵**: 16팀 녹아웃(16강 → 8강 → 4강 → 결승). 리그 라운드 사이에 끼어들며, 비기면
     승부차기, 지면 그 시즌 컵은 종료됩니다.
   - 연전이 이어지므로 체력 관리와 벤치 운용이 중요합니다.
   - **데일리 미니게임**: 순위에 영향이 없는 친선 경기를 **하루 10판**까지 바로 치릅니다.
     골드(리그의 40%)와 경기 경험치를 주고 체력을 쓰지만 **부상은 나지 않습니다**.
     자정에 다시 10판으로 채워집니다.

- 선수 61명, 5등급, 12개 포지션. 능력치는 포지션별 가중치로 계산한 오버롤(OVR)로 표시됩니다.
- 카드 일러스트는 선수 ID에서 결정되는 SVG로 그려집니다(이미지 파일 없음).
- 진행 상황은 `localStorage`에 자동 저장됩니다. 카드·시즌 구조가 바뀌면서 세이브 키가
  `football-day-save-v2`로 바뀌었으므로, 이전 버전의 진행 상황은 이어지지 않고 새로 시작합니다.
  하단의 **게임 초기화**로 언제든 처음부터 다시 시작할 수 있습니다.
- 처음 접속하면 4단계 안내가 뜨고, 헤더의 **도움말** 버튼으로 언제든 다시 볼 수 있습니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # 게임 규칙 단위 테스트 (148개)
npm run typecheck  # 타입 검사
npm run lint
npm run build && npm start
```

푸시하면 GitHub Actions(`.github/workflows/ci.yml`)가 타입 검사 → 린트 → 테스트 → 빌드를 자동으로 돌립니다.

## 배포 (Vercel)

서버나 데이터베이스가 필요 없어서 별도 설정 없이 배포됩니다.

1. [vercel.com](https://vercel.com)에 GitHub 계정으로 로그인
2. **Add New → Project**에서 이 저장소를 **Import** (프레임워크는 Next.js로 자동 인식)
3. 환경 변수 없이 **Deploy**
4. 개발 브랜치를 그대로 보고 싶다면 Settings → Git → **Production Branch**를 해당 브랜치로 변경

친구들에게 공유해 테스트를 받는 방법은 [TESTING.md](./TESTING.md)에 정리해 두었습니다.

이후 푸시할 때마다 자동으로 다시 배포됩니다. 빌드 명령은 기본값(`npm run build`)을 쓰고,
설치는 `npm ci`로 이루어지므로 `package-lock.json`이 저장소에 있어야 합니다.

## 계정과 게시판 켜기 (Supabase)

게임 자체는 서버 없이 돌아갑니다. **회원가입 · 로그인 · 클라우드 세이브 · 게시판**만
Supabase가 필요하고, 키를 넣지 않으면 그 기능만 꺼진 채로 나머지는 그대로 동작합니다.

1. [supabase.com](https://supabase.com)에서 무료 프로젝트를 만듭니다.
2. **SQL Editor**에 [`supabase/schema.sql`](./supabase/schema.sql) 내용을 붙여넣고 실행합니다
   (세이브 · 게시글 · 댓글 테이블과 접근 권한이 한 번에 만들어집니다).
3. **Project Settings → API**에서 두 값을 복사합니다.
   - `Project URL` → `NEXT_PUBLIC_SUPABASE_URL`
     (예: `https://xxxx.supabase.co`. 대시보드가 `.../rest/v1/`까지 보여줘도 그대로 붙여넣으면
     됩니다 — 코드가 알아서 잘라 씁니다.)
   - `anon public` 키(새 대시보드에서는 `publishable` 키, `sb_publishable_...`) →
     `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   이 두 값은 브라우저에 노출되어도 되는 공개 키입니다. 반면 `service_role`(또는 `secret`) 키는
   **절대 넣지 말고 어디에도 공유하지 마세요.**
4. Vercel → 프로젝트 → Settings → Environment Variables에 위 두 개를 등록합니다.
   **두 변수 모두 Production · Preview · Development 전부에 체크**해야 합니다. 브랜치 미리보기
   주소는 Preview 환경이라, 한쪽만 Preview에 없으면 그 배포에서는 로그인·게시판이 꺼집니다.
   값은 **빌드할 때 페이지에 박히므로 등록 후 반드시 재배포**해야 반영됩니다
   (Deployments → 맨 위 배포의 ⋯ → Redeploy).
   로컬에서 볼 때는 `.env.local` 파일에 같은 두 줄을 넣습니다(`.env.example` 참고).
5. 배포 후 헤더의 **로그인 → 서버 연결 확인** 버튼을 누르면 연결 · 테이블 · 키 중 무엇이
   잘못됐는지 한 줄로 알려줍니다. 문제가 없으면 `✓ 서버 연결 정상`이 뜹니다.
6. 처음에는 Supabase의 **이메일 인증 메일**이 켜져 있습니다. 친구들과 편하게 테스트하려면
   Authentication → Providers → Email에서 *Confirm email*을 잠시 꺼도 됩니다.

동작 방식:

- **키가 설정된 배포에서는 로그인해야 게임 화면이 열립니다.** 로그인 전에는 로그인 화면만
  보이고, 가입 · 로그인 후 감독실로 들어갑니다.
- 키가 없는 배포(서버 미설정)에서는 확인할 계정 자체가 없으므로 지금까지처럼 로그인 없이
  브라우저 저장만으로 동작합니다.
- 로그인하면 **이 브라우저의 진행 상황이 계정으로 올라가고**, 이후 변경은 몇 초 뒤 자동 저장됩니다.
- 다른 기기에서 같은 계정으로 로그인하면 이어서 할 수 있습니다.
- 양쪽 모두에 진행 상황이 있으면 **어느 쪽을 쓸지 물어봅니다**(고르지 않은 쪽은 사라집니다).
- 게시판은 **읽기는 누구나**, 글·댓글 쓰기는 로그인한 사람만, 삭제는 본인 글만 됩니다.
- 지금 구조에서는 세이브를 브라우저가 그대로 올리므로 수치 조작을 막지는 못합니다.
  경쟁 요소(랭킹 등)를 넣을 때는 뽑기·경기 계산을 서버로 옮겨야 합니다.

앞으로 반영할 내용(카드팩별 확률 개편, 실시간 경기 진행, 데일리 미니게임)은
[ROADMAP.md](./ROADMAP.md)에 정리해 두었습니다.

등장하는 선수 · 클럽 · 리그 이름은 **모두 가상**입니다. 어느 팀과 어느 선수를 염두에 둔
이름인지 짐작이 가도록 지었을 뿐, 실제 선수 · 구단 · 리그와는 아무 관련이 없고 실명이나
엠블럼을 쓰지 않습니다.
